# CarLog 디자인 (v1.1, 2026-11-08)

CarLog v2 앱의 새 디자인 시스템과 화면 시안이에요. **앱 코드(`carlog-v2/`, `project/`)는 바꾸지 않았어요.** 이 폴더만 따로 전달하면 돼요.

- 팔레트: Charcoal `#1E1E1C`, Sand `#D8C8B3`, Electric Blue `#2F6BFF`. 파란색은 아주 작은 표시에만 써요.
- 기준: Pleos Connect UI 디자인 가이드, Android for Cars(차량용 Android) 디자인 기준, 공모전 안내. 출처는 맨 아래에 있어요.

## 먼저 볼 것

| 파일 | 내용 |

## 디자인 규칙

1. **2초 안에 읽혀요.** 화면마다 가장 중요한 값 하나만 Feature(88dp). 문단은 3줄까지.
2. **누르는 곳은 76dp 이상, 서로 24dp 이상.** 버튼 높이 L 100 / M 80 / S 76.
3. **글자는 24dp부터.** 운전자가 읽는 글자는 Label M(24) 이상. 20은 버전 표시 같은 운전과 무관한 정보만.
4. **대비 4.5:1 이상**(Pleos 기준, 글자와 아이콘 모두).
5. **자동 애니메이션 없음.** 누르면 0.95로 줄어드는 반응만 있어요. 음량 표시도 정지된 막대예요.
6. **Sand 면은 화면당 "태그 + 주 버튼 1개"까지.** 선택된 칩·타일은 Sand로 칠하지 않고 테두리로 표시해요.
7. **파란색 규칙.** `#2F6BFF`은 Charcoal 위에서 3.71:1이라 글자·아이콘에 못 써요.
   - 쓰는 곳: 연결 점, 녹음 점, 선택 탭 밑줄(4dp), 포커스 링. 짧은 링크 글자는 `accent`(야간 `#6F98FF`, 주간 `#1A47C2`)로 써요.
   - 쓰지 않는 곳: 버튼 바탕, 넓은 면적, 파란색만으로 의미 전달. 한 화면에 2곳까지만 써요.
8. **야간이 기본.** 주간 테마는 같은 토큰으로 반전돼요. 주간에는 태그가 Charcoal이 돼요.

전체 값과 단계 색은 `tokens/carlog-tokens.json`에 있어요.

**색이론으로 본 조합 (v1.1에서 고친 이유)**
- 세 색을 OKLCH(사람 눈 기준 색 공간)로 보면 Sand는 색상각 75°의 아주 옅은 베이지, 파랑은 264°예요. 둘의 차이가 약 189°라서 거의 **보색**이에요. 파랑을 작게 쓸수록 더 또렷하게 튀는 이유예요.
- v1의 야간 패널(`#282826` 등)은 색상각이 107°(올리브 쪽)여서 Sand 옆에 두면 살짝 초록빛으로 탁해 보였어요. v1.1은 패널을 **Sand와 같은 72°** 로 다시 뽑아서, 패널과 태그가 같은 재료의 어두운 쪽과 밝은 쪽처럼 이어져요(유사색 조화). Charcoal 바탕 `#1E1E1C`는 받은 색 그대로예요.
- 경고 주황이 Sand와 같은 색상각(73°)이라 "진한 Sand"처럼 보일 수 있어서, 58°(주황 쪽)로 옮겨 의미가 섞이지 않게 했어요.
- 포인트: 패널 윗변에 1dp 빛(야간 6% Sand 밝기, 주간은 1dp 테두리)을 줘서 평평한 면이 재질처럼 보이게 했어요. 중요 메모는 옆줄 대신 주황빛이 도는 분류 배지로 표시해요.

### 글자 (Asta Sans = Pleos 시스템 글꼴, 크기/줄 높이 dp)

| 역할 | 크기/행간 | 굵기 | 자간 | 쓰는 곳 |
|---|---|---|---|---|
| Feature | 88/96 | 800 | -0.03em | 화면당 하나: 주차 위치, 남은 초 |
| Headline L·M·S | 60/72 · 56/68 · 48/60 | 800·800·700 | -0.02em | 잠금 제목, 차량 수치 |
| Title L·M·S | 40/52 · 36/48 · 32/44 | 700 | -0.01em | 대화상자 제목, 섹션 제목 |
| Body L·M·S | 30/44 · 28/42 · 26/38 | 500·400·400 | 0 | 메모 본문, 설명 |
| Label M·S | 24/32 · 20/28 | 500 | +0.01em | 메타 정보(최소 24), 버전 표시만 20 |
| Button L·M·S | 32 · 28 · 26 | 700 | 0 | 버튼 글자 |
| Nav | 28 | 600(선택 800) | 0 | 탭·레일 |

- 크기는 Pleos 타입 스케일 그대로예요. **행간만 한글 읽기에 맞게 넓혔어요**(본문 약 1.5배. Pleos 원래 값은 1.27배 정도라 두세 줄 메모가 빽빽했어요).
- 큰 글자일수록 자간을 좁히고, 어두운 바탕의 작은 글자는 아주 조금 넓혀요.
- 화면마다 제각각이던 글자 크기 18종(26·30·34·36px 등)을 위 역할로 정리했어요.
- 한글 줄바꿈은 단어 단위(`keep-all`)이고, 제목은 줄 길이를 고르게 맞춰요.

## 지금 앱과 달라지는 점 (적용할 때)

- 색: Lime(`#BCF57A`) 강조 → Sand 태그·주 버튼 + 작은 파란 점. 대응표는 `compose/MIGRATION.md`에 있어요.
- 크기: 버튼 56~72dp → 76~100dp, 최소 글자 11~13sp → 24sp.
- 받은 인계 카드(초록 패널) → Sand 태그. 보드에서 가장 눈에 띄는 요소예요.
- 반 창(1060dp 폭)이 기본 대상이에요. 지금 앱의 `wide ≥ 900dp` 기준과 1.35배 밀도 보정은 에뮬레이터에서 확인한 뒤 정리해야 해요(MIGRATION.md 6단계).

## 확정이 아닌 것 (확인 필요)

| 항목 | 지금 가정 | 확인 방법 |
|---|---|---|
| 화면 해상도·밀도 | 2560×1440, 160dpi (프로젝트 에뮬레이터 스크립트 값) | Pleos 2.1.0 에뮬레이터에서 `adb shell wm size`, `adb shell wm density` |
| 앱 창 크기 | 반 창 1060×1256, 전체 2120×1256 (상태바·Driving View·GNB를 빼서 추정) | 에뮬레이터에서 지도 옆에 띄워 확인 |
| Pleos 버튼 크기·색 값 | 가이드 그림에서 읽은 값(L 100 / M 80 / S 64) | Pleos Figma 파일 `Pleos_Connect_design_assets_215.fig` |
| 주야간 전환 방식 | 시스템 다크모드를 따른다고 가정 | 에뮬레이터에서 주야간 전환 시 `uiMode` 확인 |
| 주행 중 표시 | Pleos 가이드는 CarUxRestrictions로 직접 제한. Google 기준으론 주차용 앱은 주행 중 OS가 가릴 수 있음 | 에뮬레이터 주행 시뮬레이션에서 07 화면이 실제로 보이는지 확인 |

## 공모전 관련 메모

- 디자인은 따로 점수를 매기는 항목이 아니에요. 다만 1차 심사 "차량특화성"(주행·정차 맥락)과 "기술 활용성"(SDK를 핵심 경험에 활용)이 화면에서 보이도록 했어요: 차량 연결 상태, 주행 중 잠금, 음성 녹음(STT), 읽어주기(TTS).
- 기획서 7번 참고자료(가산점)에 `png/00-context_night_display.png`와 주요 화면 PNG를 넣을 수 있어요. 시연 영상에는 목업도 인정돼요.
- 시안에는 실명·연락처가 없어요(프로필은 아버지·어머니·자녀).
- 글꼴 Asta Sans는 OFL 라이선스예요. 아이콘은 이 폴더에서 직접 그린 것이에요.
